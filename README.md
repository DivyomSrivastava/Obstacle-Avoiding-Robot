# Obstacle-Avoiding-Robot
**Arduino-based 4WD Obstacle Avoiding Robot using Arduino Uno, L298N Motor Driver, HC-SR04 Ultrasonic Sensor, and SG90 Servo. The robot autonomously detects obstacles, scans its surroundings, selects the clearest path, and navigates without human intervention.**
